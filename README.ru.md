# Codex Workforce

**Два смешанных профиля. Законченные блоки работы. Ревью готового результата.**

[English](README.md) · [Профили](docs/profiles.md) · [Установка](docs/installation.md)

Агенты и skills для Codex: **GPT-6 Astra** отвечает за оркестрацию, сложные решения
и приёмку, **GPT-5.5** выполняет основной объём реализации. В обоих профилях работают
обе модели. Пакет не требует GSD, отдельного сервера или нового менеджера задач.
Это независимый проект, не официальный продукт OpenAI.

## Установка и обновление

Нужны Node.js 22+, npm, Git и Codex с поддержкой пользовательских агентов,
явного выбора model/effort и доступом к обеим моделям.

```sh
npx --yes github:shanja-glinka/codex-workforce install
npx --yes github:shanja-glinka/codex-workforce update
npx --yes github:shanja-glinka/codex-workforce status
npx --yes github:shanja-glinka/codex-workforce uninstall
```

Пакет запускается напрямую из публичного GitHub. Для фиксированной версии используйте
`github:shanja-glinka/codex-workforce#v1.0.0`. При обновлении фиксированной установки
укажите новый тег. После установки откройте новую сессию Codex.

`update` заменяет предыдущие файлы пакета и удаляет устаревшие файлы, которыми он
владеет. Чужие агенты, настройки и текст инструкций сохраняются. При конфликте
установщик сообщает конкретный путь. Подробности — в [контракте установки](docs/installation.md).

Можно сразу запустить Codex с реальными настройками выбранного профиля:

```sh
codex -p workforce-standard
codex -p workforce-enhanced
```

Названия продукта, ролей и команд не зависят от поколения моделей. Политика моделей
хранится в `profiles.json` и обновляется с версиями пакета; изменения описываются
в [журнале релизов](CHANGELOG.md).

## Как выбирается режим

Перед новой задачей реализации оркестратор объясняет профили и спрашивает:
**«Как выполнять работу: стандартным или усиленным профилем?»**
До вашего ответа исполнение не начинается. Можно сразу указать профиль в запросе.
Выбор сохраняется на задачу и её продолжения; подагенты наследуют его без повторных
вопросов. Для запуска без человека профиль должен быть заранее указан в задании.

| Ответственность | Стандартный | Усиленный |
| --- | --- | --- |
| Оркестратор | Astra low | Astra high |
| Ограниченное исследование | GPT-5.5 medium | GPT-5.5 medium |
| Основная реализация | GPT-5.5 high | GPT-5.5 high |
| Неописанное сложное решение | Точечное подключение Astra | Отдельный блок Astra high |
| Ревью готового блока | GPT-5.5 xhigh | GPT-5.5 xhigh |
| Приёмка крупного этапа | Astra high | Astra high |

Стандартный подходит, когда решение достаточно описано. Усиленный — когда нужно
разобраться с неопределённой архитектурой или найти алгоритм. Даже сложный, но точно
описанный алгоритм может реализовывать GPT-5.5. Уровни Astra xhigh/max применяются
с объяснением причины, а не автоматически из-за длительности задачи.

**Текст инструкции не переключает модель текущего оркестратора.** Выберите Astra
и нужный effort средствами клиента. Агент обязан сообщать о несовпадении, а не
изображать переключение. Установщик не переписывает `config.toml` и разрешения.

## Что изменяется в работе

- Один план и исходная цель пользователя; просьба проанализировать не разрешает правки.
- Исполнителю передаётся законченный результат с примером приёмки и границами владения.
- Исполнитель сам проверяет конвенции, документацию и поведение своего блока.
- Независимое ревью — после готового существенного блока, приёмка Astra — перед
  закрытием крупного этапа. Нет аудитора на каждую правку.
- Замена доказывается цепочкой: прежнее объявление → фактическая замена → потребители.
  Количество файлов и успешная сборка не подменяют результат.
- Исправления возвращаются владельцу одним пакетом; повторяются затронутые проверки.

Файлы хранятся в `CODEX_HOME` (по умолчанию `~/.codex`), а ссылки на skills — в
`~/.agents/skills`, откуда Codex их обнаруживает. Глобальная инструкция добавляется
отдельным управляемым блоком. Локальные копии в проекте могут иметь приоритет —
их миграция описана в документации.

Пакет не гарантирует идеального следования инструкциям или экономии токенов.
Стоимость оценивается по принятому результату и доступной телеметрии, с учётом
повторных попыток и исправлений. Тесты установщика не запускают платные модели.
